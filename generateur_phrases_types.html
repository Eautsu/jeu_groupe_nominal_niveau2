Générateur de phrases

Pour le bonus du Défi du Groupe Nominal, niveau 2 — outil pour l'adulte.

  1. Tirer des cartes, comme dans le jeu.
  2. Pour chaque phrase proposée avec ces cartes : 👍 Garder si elle a du sens, 👎 Non sinon. Vous pouvez aussi construire votre phrase.
  3. Enregistrer pour le jeu, puis déposer le fichier dans le dépôt du jeu, à la place de l'ancien.

Dans le jeu, l'élève reconstitue les parties en couleur avec ses cartes (groupes nominaux) et conjugue le verbe. Le reste de la phrase est déjà écrit.

Phrases possibles avec ce tirage

Construire une phrase

Touchez les cartes pour écrire, ou tapez. Entre crochets, dans l'ordre : le sujet, le verbe conjugué, puis s'il y en a un, le complément ou l'adjectif. Après une préposition : [Le coq] [joue] avec [la poule].
