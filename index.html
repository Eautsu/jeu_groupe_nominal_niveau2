Règle du jeu : « Le Défi du Groupe Nominal », niveau 2

Au niveau 2, chaque carte porte un seul mot : un déterminant, un nom, un adjectif ou un verbe. Le dos indique son genre et son nombre (couleur) et sa nature (symbole).

1. Le contrat

  • Le joueur pioche une carte Joker.
  • Il choisit une pile de cartes Défi : on ne voit que les points. Il découvre la consigne et le nombre de cartes.

2. Les défis

  • Genre et nombre : retourner les mots masculins, féminins, singuliers, pluriels…
  • Nature : retourner les déterminants, les noms, les adjectifs ou les verbes.
  • Compatibilité : retourner les noms qui vont avec un déterminant (« mon … »), ou les adjectifs qui vont avec un nom (« chat … »).

3. Le tri

  • Bonne carte : elle est gagnée. Mauvaise carte : c'est une erreur.
  • 1re erreur : on continue. 2e erreur : le défi est échoué.
  • Omission : quand le joueur dit « J'ai fini », s'il reste une carte valide sur la table, le défi est échoué. Exception : un mot à double nature qui ne répond à la consigne que par sa seconde nature (« petits » comme nom) est facultatif : retourné, il est gagné ; oublié, il ne compte pas.
  • Défi réussi : les points de la carte Défi. Défi échoué : 1 point par carte valide trouvée.

4. Le bonus : reconstituer une phrase

Après un défi réussi, le joueur peut reconstituer une vraie phrase choisie par l'adulte dans la banque de phrases (« Hier, … … … dans le jardin. »). Il place les cartes dans les cases : le groupe nominal sujet, et parfois un complément, un adjectif ou un complément introduit par une préposition (« Le coq joue avec … »). Certaines cartes sont des pièges (le / les, petit / petite, un autre nom). Un autre nom ou un autre adjectif est accepté s'il donne aussi une phrase qui a du sens. Le joueur écrit le verbe conjugué, au temps demandé par un mot comme « hier » ou « demain », sinon au temps de son choix. Une faute dans le radical du verbe est acceptée si la terminaison est juste. 2 ou 3 essais selon le réglage ; après le dernier, le jeu montre la phrase de départ. En option, un adulte peut valider à sa place. +1 point par carte posée et pour le verbe. En cas d'erreur, on ne perd pas de point. Si la banque est vide, il n'y a pas de bonus.

Les jokers

  • Rejoue sans risque : 3 vies au lieu de 2.
  • Si tu réussis, tu doubles les points.
  • Si tu te trompes une seule fois, le défi est perdu.
  • Annule la dernière action (une fois).
  • Échange une carte de la table avec la pioche.
  • Échange toutes les cartes de la table (avant d'en retourner une).
  • Transforme un mot : féminin ↔ masculin, ou singulier ↔ pluriel, s'il existe dans le jeu.
